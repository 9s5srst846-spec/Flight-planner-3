# Flight Planning Suite

A browser-based flight planning calculator for C172/C182 ground-school calculations.

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and this `README.md` to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. GitHub will provide the site URL.

The app is a static HTML/CSS/JavaScript site, so no server or build step is required.

## iPhone

After publishing with GitHub Pages, open the site in Safari and use **Share → Add to Home Screen**.

> Note: the current HTML imports Google Fonts, so the interface's custom fonts require an internet connection. The calculator code itself is contained in the HTML file.
